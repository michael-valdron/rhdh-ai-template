# AI samples

## Usage in rhdh-ai-template

This repository is being used in [rhdh-ai-template repository](https://github.com/redhat-developer/rhdh-ai-template) as the Software Template source code for users to start with.

This repository is a copy of the AI Lab recipes source code under [ai-lab-recipes](https://github.com/containers/ai-lab-recipes/tree/main/recipes).

To contribute or make an update to these samples, open a Pull Request under the upstream [ai-lab-recipes repository](https://github.com/containers/ai-lab-recipes/tree/main/recipes). To pull in the latest changes to this repository, run `../scripts/pull-sample-apps.sh`, and commit the changes.

You can then re-generate the Software Templates in [rhdh-ai-template repository](https://github.com/redhat-developer/rhdh-ai-template) to use the latest AI samples from this repository.

## Usage in rhdh-ai-template @ experimental

For the experimental Software Templates in [rhdh-ai-template repository](https://github.com/redhat-developer/rhdh-ai-template), use the `experimental` branch. The `experimental` branch is independent of other repositories and it is manually curated or maintained.
