# Experimental AI Software Templates

New candidate AI templates can be added under the `templates` folder. See `templates/sampleapp` for a sample template directory structure. Each template should have its own sub-directory under the templates folder.

## Usage

To use the experimental Software Templates on RHDH or Backstage, please refer to the [rhdh-ai-template repository](https://github.com/redhat-developer/rhdh-ai-template) for the [USAGE guide](https://github.com/redhat-developer/rhdh-ai-template/blob/main/docs/USAGE.md).

 
## Contributing

Follow the local [CONTRIBUTING guide](./docs/CONTRIBUTING.md). Experimental application sources are maintained in [samples](./samples) on this `experimental` branch. Edit the sources there and run `bash generate.sh` to regenerate the templates.

## Troubleshooting

For more information about troubleshooting tips, please refer to the [rhdh-ai-template repository](https://github.com/redhat-developer/rhdh-ai-template) for the [TROUBLESHOOTING guide](https://github.com/redhat-developer/rhdh-ai-template/blob/main/docs/TROUBLESHOOTING.md).

For information regarding adding custom models that are not pre-packaged as part of the Podman Desktop AI Lab extension see [adding-custom-models.md](./docs/adding-custom-models.md)
